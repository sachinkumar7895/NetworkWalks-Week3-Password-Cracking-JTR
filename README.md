# NetworkWalks-Week3-Password-Cracking-JTR

## Project Overview

This repository contains my Week 3 practical work completed as part of the **NetworkWalks Cybersecurity Internship (Batch B084)**.

The project covers two essential modules focused on password recovery using John the Ripper (JTR), Johnny GUI, and NetworkWalks online tools.

## Week 3 Essential Modules

### W3-PM1: Password Cracking with JTR

### Tools Used:

- John the Ripper (JTR)
- Johnny GUI
- Windows
- PDF Hash Extractor
- Notepad

## Tasks Performed:

- Downloaded and configured John the Ripper and Johnny GUI.
- Extracted the password hash from the assigned locked PDF.
- Saved the extracted hash in a text file.
- Loaded the hash into Johnny and started the password recovery process.
- Tested the recovered password by opening the PDF.

## W3-PM2: Password Cracking with NetworkWalks Tools

## Tools Used:

- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web Browser
- Windows

## Tasks Performed:

- Uploaded the assigned locked PDF files to the NetworkWalks Hash Calculator.
- Extracted and copied the PDF password hashes.
- Submitted the hashes to the NetworkWalks Password Cracker.
- Performed password recovery.
- Verified the recovered passwords by opening the PDF files.
